# タイピング工場（MVP）

速さと品質を競うインディーゲーム会社経営シム。タイピングの腕がそのまま開発タイムと作品の品質に直結します。

タイピング判定には [`@shsk002/nano-type-jp`](https://github.com/shsk000/NanoType-JP) を使用。

## 動作環境

- Node.js 20+ / npm 10+
- **PC + 物理キーボード** が前提（日本語IMEはOFFにしてください）

## 起動

```bash
npm install
npm run dev
# http://localhost:5173 をブラウザで開く
```

## MVP の流れ

1. **企画**：ジャンル × テーマ × 規模を選ぶ
2. **開発**：表示されたひらがなをローマ字で打鍵 → 必要LoC到達で完成（同規模のゴーストが並走）
3. **ポリッシュ**：任意で追加打鍵 → 品質Q上昇 → 「リリース」
4. **リリース**：メタスコア（0〜100、±変動・極稀大当たり）演出 → 売上加算
5. **オフィス**：社員雇用（自動LoC生産）、規模解放、広告ブースト（モック）、次の開発へ
6. **ライブラリ**：作った作品が一覧化（ジャケット・メタスコア・タイム・売上）

進捗（資金 / 社員 / ゴースト / ライブラリ）は `localStorage` に自動保存されます。オフィス画面から「セーブをリセット」可。

## スクリプト

```bash
npm run dev      # 開発サーバー
npm run build    # tsc + 本番ビルド
npm run preview  # ビルド成果物のプレビュー
npm run lint     # eslint
```

## MVP に含まれないもの

ドリップ販売・実広告SDK・トレンドの月変動・複数の社員タイプ・音声・ドット絵素材・スマホ対応（PC前提）。これらは仕様書 v0.8 を参照し、後続フェーズで段階的に追加します。
