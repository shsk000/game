# ゲーム設計 北極星スキル

## ロール（あなたの立ち位置）

**あなたは経験豊富なゲームプロデューサーです。**

- **面白さと目的を両立させる**：作品を面白くすることと、事業目的（広告収益化）の達成は対立しない。長く遊ぶユーザーが一番広告を見る以上、「面白くて続く」設計がそのまま「稼げる」設計になる。常に両方を満たす案を選ぶ。
- **自分で考えて進める**：計画・設計で判断がつく箇所は、このスキルの確定方針（特に §10 の判断基準4つ）に照らして自分で決め、手を止めない。
- **迷ったら必ず聞く**：確定事項にない／方針が割れる／後戻りしにくい大きな判断（コアループ・主要システム・大きな投資）は、勝手に進めず論点を整理してオーナー（shsk）に提示し、決定を仰ぐ。
- **プロアクティブに確認する（責務）**：目的達成に必要だと判断したことは、ユーザーから言われるのを待たず**自分から確認・提案する**。「詰めたい場合は言ってください」のような受け身の保留は、プロデューサーの責務放棄。
  - 自分で決められること（北極星に照らして判断可能・後戻り可能・数値や表現の調整）→ 決めて手を動かす（原則2）。
  - 自分で決めてはいけないこと（後戻りしにくい・方針が割れる・法務/商用リスク・大投資）→ 待たずに**自分から論点を整理して確認を取りにいく**（原則3）。
  - やってはいけないのは「未確定のまま放置」「ユーザーが言い出すまで待つ」こと。必要な確認は自分から起票する。

## 1. コンセプト（何のゲームか）

プレイヤーは**インディーゲーム会社の社長**。自分でコードを打つ（タイピング）ことが開発作業そのもの。

- **制限時間（締切）はない。** 必要コード量を打ち切るまでの**実時間（開発タイム）が計測**され、速く打つほど早く完成する。
- 完成後は**任意で好きなだけ打って品質を磨ける（ポリッシュ）**。
- タイピングが遅くても**失敗しない（誰も弾かれない）**。速い人は記録を狙い、磨きたい人はとことん磨く。

**設計思想**：タイピングの速さ・正確さが、開発タイムと品質に直接変換される。誰も弾かず、上達がそのまま結果になる。**タイピングは最後まで主役**。

一行で言うと → 「コードを打ち切ってゲームを完成させ、その速さが記録に、磨いた分だけ品質になる」。

---

## 2. 事業目的と前提（最重要・確定）

本プロジェクトは**リアルマネーの収益化を目的**とする。面白さは目的であると同時に収益の土台。
**長く遊ぶユーザーが結局一番広告を見る** → 「面白くて続く」設計＝「稼げる」設計。この 2 つは対立しない。

### 収益化の基本方針（確定）
- 収益手段は当面 **広告に一本化**。課金は将来拡張の余地を残すのみ（当面実装しない）。
- 広告は **リワード（任意視聴）を主役**にする。「自分から見たくなる／見たほうが進めやすい」を最優先。
- **強制広告（インタースティシャル）は区切りでたまに**。主役はあくまでリワード。
- **大原則：広告を「進行の人質」にしない。** 自力でも全規模クリア可能を保ち、広告は「見ればさらに楽・得」の位置に置く。嫌々見せる広告は離脱を生み、離脱したユーザーは二度と広告を見ない。

### 広告 3 分類
| 種類 | 見せ方 | 扱い |
|---|---|---|
| リワード | 任意・見ると報酬 | ◎ 主役 |
| インタースティシャル | 強制・区切りで全画面 | △ 区切りでたまに |
| バナー | 常時表示・単価低 | ○ 補助（任意） |

### プレイ環境（確定）
- **PC 横画面を優先。物理キーボードでの高速タイピングを前提。**（スマホのフリックでは成立しない設計を選べる）
- スマホ対応は当面スコープ外（将来検討）。

### 進め方（確定）
- 判断に迷う箇所はプロデューサー（Claude）が論点を整理して提示し、方針はオーナー（shsk）が決定する。

## 3. すべてが「タイピングの腕」に変換される

| 要素 | 役割 |
|---|---|
| タイピング速度（WPM） | 速いほど開発タイム短縮＝良い記録／磨く余力も増える |
| 正確さ（ノーミス） | ミスはやり直しで時間ロス。バグ混入で品質減 |
| コンボ／ノリゲージ | ミスなく速く打つと倍率 UP。途切れると惜しい（前向きな緊張） |
| 自動生産（社員） | 自分と並行してコードを積む＝開発タイムの恒常的底上げ |
| ゴースト | 過去最速タイムが並走。追い抜く目標＝失敗なしの緊張 |
| 品質 | ポリッシュで打った量に応じて上昇＝売上に直結 |
| 広告（加速/効率） | 開発加速・ポリッシュ効率・売上ブースト＝任意の上乗せ |

**自動化が進んでも、より大きい作品に挑めば手で打つ量はまた増える。** 「自動化したから楽」ではなく「自動化したぶん、もっと上を狙える」。**タイピングは決して卒業させられない。**

## 4. コアループ（経過時間が主役）

```
作品を企画（ジャンル×テーマを選ぶ）
  → 【開発】必要コード量を打ち切れ（制限時間なし・自ペース）
       かかった実時間 = 開発タイム（速いほど良い記録）／ゴースト並走
  → 完成（品質：最低保証）
  → 【ポリッシュ】任意で追加タイピング → 打った量だけ品質 UP（やめどきは自分で決める）
  → リリース → 品質 × 企画相性 × トレンド で売上
  → 売上を投資（社員/設備/新ジャンル解放）→ もっと大きい作品へ
```

### 品質ポリッシュ＝本作の肝【方式 B・確定】
完成後、**任意で**好きなだけ追加コードを打てる。打つほど品質スコアが上がる。**やめどきはプレイヤーが決める。**
- 速く打てる人 → 早く完成 → ポリッシュの余力たっぷり → 高品質 → 高売上
- 上達のご褒美が「開発タイム短縮」と「高品質＝高売上」の両方で返る。

### 前向きな緊張【確定】
制限時間を撤廃した代わりに、**「超えると気持ちいい」**緊張を入れる（初心者を弾かず上級者を燃やす）。
- **ゴースト**：同規模の自己ベストが並走。抜けば記録更新、負けてもペナルティなし（レースゲーム手法）
- **ライバル会社**：同ジャンルを先にリリースで話題独占ボーナス。負けても破滅しない
- **ノリゲージ**：ミスなく速く打ち続けると上昇→打鍵効率・品質ボーナス。ミスで途切れて惜しい

> いずれも「間に合わないと失敗」ではなく「超えると得・気持ちいい」。**初心者を弾かず母数を増やす＝収益目的と整合**。

### 難易度＝作品規模
作りたい作品が大きいほど必要コード量が増える＝打つ量が増えて手が忙しくなる。制限時間がないので「詰む」ことはない。
**1 作のプレイはテンポ重視で数十秒〜数分**（上位規模でも 1 作 3 分以内）。短ループ反復でプレイ回数＝広告接触機会を最大化。

## 5. 評価と販売（中毒と収益の接続）

### 評価＝メタスコア【確定：メタスコア中心】
- 開発中：**品質メーター＋期待度の予感**（相性×トレンド×品質）でリリース前から手応え
- 完成後：**メタスコア 0〜100** を演出付きで開示＝ガチャを開ける瞬間
- **±変動（ブレ）が中毒の肝**：同じ作りでも毎回ぶれる。ごく低確率で大当たり（神ゲー認定）
  - ※ブレ/ガチャの実装は後続版で調整あり。最新は最大版 spec を見る
- スコア帯ごとのフレーバーレビュー（90+「傑作」〜49「企画倒れ」）
- 評価は次へ繋がる：**ファン数**（次回作の初動底上げ）／**名声**／**自己最高記録**

### 販売＝放置でジワ売れ【確定】
売上は「一瞬で確定」ではなく「**しばらく売れ続ける**」。離れている間も資金が貯まり、戻る理由になる。
```
リリース → 初動（メタスコア×ファン数×規模）→ 数日かけてジワジワ売れる → 売上確定 → 投資
```
- **設計の肝**：高メタスコア → 長く売れ続ける → 戻るたびに資金が増えている。「いい物を作る」と「放置で儲かる」が一本に繋がる。
- 中盤以降は**複数作品の同時販売**（ヒット作のロングテール＋新作の初動が重なる＝会社が育つ実感）。

## 6. 面白さの柱とメタ進行

### ジャンル相性システム【面白さの柱・確定】
- 1 作 = **ジャンル 1 × テーマ 1**。各組合せに**隠れた相性値**（企画ボーナス 0.7〜2.0 倍）
- **初めて作るまで相性は不明**＝開拓のワクワク。作ると図鑑に記録され以降は可視化
- 「神の組合せ」は全体の数%だけ仕込む＝探索のロマン。一部に地雷（学習要素）
- **トレンド**（流行ジャンル/テーマに合致でボーナス・毎回変動）／**新規開拓ボーナス**／**アンロックで組合せ空間が拡大**
- トーン：**現実ベース＋ネタ混在**（Game Dev Story 系。「ホラー×温泉」「レース×寿司」等）
- 初期：ジャンル 12 種・テーマ 15 種を想定（序盤はジャンル 3＋テーマ 5 から）

### メタ進行 3 本柱【中毒性の中核・確定：バランス型】
1 周は数分。何百周もさせる燃料は「周をまたいで蓄積するもの」。
1. **会社が育つ（経営）**：資金・社員・設備・オフィスの永続強化。「あと少しで次」の連鎖
2. **コレクションが埋まる**：作品ライブラリ／ジャンル組合せ図鑑／実績・称号
3. **記録が伸びる（やり込み）**：最速タイム・最高品質・最高売上・最高 WPM・最高コンボ

設計方針：序盤は柱 1、中盤から柱 2、長期は柱 3。**常にどれか 1 つは「あと少しで達成」**の状態を作る（ツァイガルニク効果）。

## 7. 広告と経済（収益の生命線）

### 広告が自然に刺さる瞬間（リワード・任意・主役）
| タイミング | 見せ方 |
|---|---|
| 開発が長引く | 「クランチ稼働」＝生産 2 倍（開発タイム短縮） |
| ゴースト/ライバルに負けそう | 一時加速＝記録更新を狙える |
| ポリッシュ中 | ポリッシュ効率 2 倍＝同じ打鍵で高品質 |
| リリース直後 | ローンチ広告＝売上 +50% |
| 再訪時 | 離席中の自動生産成果を 2 倍 |
| 未知の組合せ | 市場調査＝相性を一部開示／最低売上保証 |

「広告を見て広告キャンペーンを打つ」はテーマ的にハマる。

### 強制広告（インタースティシャル・補助）
- 配置：ステージクリア時／一定本数リリースごと／自然な切れ目
- **禁止：開発・タイピング・ポリッシュ中の割り込み**（集中の最中に挟むと最悪の体験）
- 1 セッションの強制回数に上限を設ける

### 経済バランスの原則【実装で守る】
1. **広告なしでも全規模クリア可能**（人質化しない）
2. **広告ありだと体感 1.3〜2 倍お得**（見たくなる強さ、でも壊れない）
3. **資金インフレを管理**：上位規模ほど売上増だが社員/設備コストも指数的に上げて青天井を防ぐ
4. **テンポ維持**：1 作の完結を数十秒〜数分に保つ

> 売上式・相性値・トレンド頻度・広告効果などの**具体数値は「叩き台」**。最新の確定値は最大版 spec を見る。

### 当面入れない（離脱リスク）
- スタミナ制限、「腐る」プレッシャー系 ── 楽しむ前に義務感を生むので入れない

## 8. 作品ビジュアルと素材方針

### 作品は「見える形」で存在させる【確定：面白さの本体】
作った作品をテキストと数字だけで表すのは魅力を殺す。作品に絵・タイトル・ジャケットがあってこそ、コレクション欲・達成感・「自分が作った」感が生まれる。**素材は「コスト」ではなく面白さの本体の一部**。

- **組合せ合成**：固定の完成品を量産せず、**パーツの組合せで自動合成**
  `作品ジャケット = 背景（ジャンル）＋ シンボル（テーマ）＋ 自動生成タイトル`
  → ジャンル 12＋テーマ 15 のパーツで 180 通りが生まれる
- **自動タイトル生成**：単語テーブル＋テンプレで「呪いの大浴場」「爆走！回転寿司 GP」等を量産（素材ゼロ）
- スタイル：**ドット絵／レトロ調**（AI 生成のアラが目立たない・世界観と合致・組合せ合成と相性最高）

### 素材の作り方【収益目的ゆえ権利を厳密に】
- AI でパーツを多めに生成 → 選別 → **ピクセルエディタで人間が加工** → 組合せ合成
- ⚠️ **純粋な AI 生成物（プロンプトのみ）は著作権保護されにくい** → 人間の創作的加工を必ず一手間入れて保護を組み込む
- 使用ツールは**商用ライセンス明記の有料プラン**を選ぶ。無料素材も商用可・クレジット要否を素材単位で確認・記録
- ※情報は 2026 年時点。AI と著作権の状況は変化が速いので実装着手時に最新規約を再確認

### 段階的な作り込み
- 初期（プロト）：UI は CSS、ジャケは背景色＋絵文字シンボルの簡易合成、効果音なしでも成立 → **ロジックに集中**
- 磨き込み期：AI 生成ドット絵に差し替え、効果音・社員アバター・オフィス見た目を実装
- **「面白いと確認してから絵を作り込む」。ただし作品が見える仕組み自体は最初から入れる**（テキストだけにしない）

## 9. ステージ構成・技術メモ（要点）

### ステージ（会社の成長段階）
| 段階 | 規模 | 作れるゲーム |
|---|---|---|
| 1 自宅の一室 | 自分で全部打つ | ミニゲーム |
| 2 小オフィス | 社員 1〜2 人 | スマホゲーム |
| 3 スタジオ | チーム開発 | インディー大作 |
| 4 中堅企業 | 複数職種 | 話題作 |

### 技術メモ
- 形態：**ブラウザゲーム（HTML5）**。PC ネイティブは広告規約/SDK 面で不向き
- 実装の中核：**経過時間計測・ゴースト（自己ベスト）の保存と並走表示・必要コード量到達判定・ポリッシュの品質加算・広告加速の反映**
- セーブ：localStorage（離席時刻を保存し再訪時にオフライン報酬を計算）
- 広告 SDK 候補：Google H5 Games Ads／ポータル配信（CrazyGames・Poki 等）。**視聴完了コールバック後に報酬付与＋フォールバック必須**

## 10. このゲームの一番の魅力（判断の最終基準）

> **どれだけ速く打ち切れるか。そこからどこまで磨き込めるか。**

新機能・変更を判断する時、最後にこの 4 つに照らす：
1. **タイピングが主役**であり続けるか（卒業させていないか）
2. **誰も弾かない**か（自力で全規模クリア可能か）
3. **広告を人質にしていない**か（見れば得、でも見なくても進める）
4. **長く遊ぶ人が一番得する**設計か（中毒性＝収益が一本に繋がるか）
