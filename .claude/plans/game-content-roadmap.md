# Plan: ゲーム内容ロードマップ（v0.9 → v1.0 → v1.5 以降）

## Context

### なぜこの計画が必要か
v0.9 baseline は「タイピング MVP + 計画 → 開発 → リリースの基本ループ + オフィス + 採用 + 図鑑 + 実績 + ライブラリ」まで実装済みで、骨格としては成立している。一方で、現状の体験には以下の構造的な弱点がある。

- **育成軸の柱が起動していない**: `equipment.ts` の `qualityBonus / perfBonus / comboBonus` が `computeQuality` に統合されておらず、装備が事実上「死にデータ」。中盤以降の伸び代が見えづらい。
- **達成リズムの粒度が荒い**: 実績が 8 個しかなく、序盤〜中盤の自然な目標感が薄い。
- **探索空間が狭い**: テーマ tag 9 種 × カテゴリ tag 7 種が用意済みなのに相性計算に活かされておらず、「次は何を試そう」が固定ペアに収束しやすい。
- **演出フィードバックが弱い**: バグ修正完了の緑フラッシュや特大ヒット時の紙吹雪などが未実装で、Kairosoft 水準のリアクション設計に届いていない。
- **発表前に必要な摩擦解消が未完**: 60 秒チュートリ作品、殿堂入り画面、装備 3 段階アップグレード、BGM/SE 一式が無く、v1.0 として外に出せる完成度ではない。

### 目指す姿
- **v0.95（短期 / 1-2 週間）**: 既存システムの磨き込み。死にデータ起動・実績拡張・演出補強・OfficeScreen 分割で「触り心地」を Kairosoft 水準に寄せる。
- **v1.0（中期 / 1-2 ヶ月）**: 発表可能 MVP の完成。殿堂入り・装備アップグレード・コードスニペット 3 倍・BGM/SE・チュートリで、外に見せられる状態へ。
- **v1.5 以降（長期）**: ライバル会社 / 複数ライン / 育成 XP / 季節イベント / シーズン制で、長期プレイの動機付けを構築する。

### 戦略
**短期 Top 5 で「育成軸復活 × 達成リズム × 探索深化 × 演出品質 × 序盤摩擦解消」を同時に潰し、v1.0 中期タスクの土台を作る**。とくに S1（装備実機接続）/ S2（実績拡張）/ S5（tag 相性）は UI 改修中の隙間時間に着手できるため、並行で進める。

## 今すぐやるべき Top 5（実装着手順、理由付き）

UI 改修と並行できるものを優先。**データ層・関数単体改修のみで完結し、UI に手を入れずに効果が出る**順に並べた。

| 順位 | 項目 | 並行可の理由 | 中核価値 |
|---|---|---|---|
| 1 | **S1 装備実機接続** | データ層改修のみ、UI は既存装備パネル流用可 | 死にデータ起動 = ゲーム最大構造問題（育成軸欠落）の即解消 |
| 2 | **S2 中間実績パック** | `achievements.ts` 単体編集、UI 不要 | 8 → 24 で全プレイ区間に達成リズム |
| 3 | **S5 テーマ tag 相性** | `categoryAffinity` 関数内のみ、UI 影響ゼロ | 探索空間が即倍化、コンテンツ追加無しで「次は何試そう」が増える |
| 4 | **S3 バグ修正緑フラッシュ + S4 特大ヒット演出** | 演出層追加のみ、ロジック不変。tasks.md 負債消化セット | フィードバック品質を一気に Kairosoft 水準へ |
| 5 | **M7 60 秒チュートリ作品** | 初期化フロー追加のみ、既存画面そのまま使用 | 離脱率に直結、発表前に必須 |

### 戦略まとめ
Top 5 で「**育成軸復活 × 達成リズム × 探索深化 × 演出品質 × 序盤摩擦解消**」を同時に潰し、v1.0 中期タスクの土台を作る。S1 / S2 / S5 は UI 改修中の隙間時間に着手可。

### 着手順の具体的シーケンス
1. **Day 1-2**: S1（`computeQuality` への bonus 統合、テスト追加）
2. **Day 2-3**: S2（`achievements.ts` 16 件追記、進捗トラッカー結線）
3. **Day 3-4**: S5（`categoryAffinity` 内に tag × tag テーブル +2 補正）
4. **Day 4-6**: S3 + S4（演出層 `BugFlash` / `HitFireworks` コンポーネント追加）
5. **Day 6-8**: M7（初回起動フラグ + チュートリ作品自動生成 + サービス資金）
