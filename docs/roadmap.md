## v0.21「投資」— 金の使い道（オーナー指定・[spec.md](./v21/spec.md) 展開済み）

**問い：稼いだ金で何を買えば楽しいか？**

現状、資金の使い道は「採用・規模解放・借金返済」だけ。オーナー指定の2本を軸にする：

- **ジャンル・テーマをお金で購入**（オーナー指定）
  - 未解放のジャンル/テーマを資金で個別購入できる（人気なほど高い 🔧）
  - 既存のステージ解放（累計売上）との関係は spec 時に確定 🔧：
    案A=併存（ステージ到達で無料解放 or 先行して金で買う＝「先行投資」）／案B=購入制に一本化
  - 「作りたい組合せを金で引き寄せる」＝探索（図鑑）への投資になる
- **お金で社員を育成**（オーナー指定）
  - 研修コマンド：資金を払って対象社員に exp を直接付与 🔧（例：¥50万 = exp 20。リリース獲得より割高だが確実）
  - 上位研修（レベルキャップ付近で解放）などの階段は spec 時に設計
  - 「リリースで自然に育つ」＋「金で加速する」の2路線＝固定費増（給与）とのトレードオフ
- オフィス設備（バグ抑制サーバー等）は**任意枠 🔧**：上記2本の手応えを見て入れるか判断
- **判断ゲート**：進行シミュレーション（mobile 8〜16作・分布ガード）を金の近道込みで再検証

## v0.22「採用ガチャ」— 引く楽しみ（オーナー指定）

**問い：採用を「作業」から「引きの快感」にできるか？**

- **社員ガチャ**：採用を抽選演出に。**ランク S / A / B** で能力（basePower 帯・specialty 数 🔧）に明確な差
  - 叩き台 🔧：B（70%・basePower 0.2〜0.4）／A（25%・0.4〜0.55）／S（5%・0.55〜0.7＋固有ボーナス?）
  - 排出演出（ドット絵カード開封・ランク色・SE）— PixelLab 素材はオーナー承認制
  - 単発/10連 🔧、天井の有無 🔧、既存の REFRESH_COST（候補リフレッシュ）との統合を spec 時に確定
  - 広告連動（無料ガチャ1日1回等 🔧）は北極星「広告は人質にしない」に照らして設計
- **判断ゲート**：S 排出が分布ガード（95は終盤）を壊さないこと（S でも Lv1 なら charPower 上限は変わらない設計を維持）

## v0.23「山場と終わりなき経営」— 緊張とエンドゲーム

**問い：なぜ「もう1本」作りたくなるか？ aaa の先に何があるか？**

- 依頼仕事（締切つき）：達成で高額報酬・失敗で信頼低下 🔧 — 打鍵に「急ぐ理由」を作る

- エンドゲーム：GOTY（年間大賞）／殿堂（メタ95ギャラリー）／周回 🔧
