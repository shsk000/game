## 0. この版で変えること（改訂背景）

### オーナー評価（2026-07-05）
v0.14 の実装後も「**今は面白くない。音を足しても全く解決になっていない**」。

### 診断（v0.14 の教訓）
- 現行タイピングは**1本道の文を順番に打つだけ**。選択も駆け引きもリスクリターンも無い
- イベントを足しても「同じ打つ作業が増えた」だけで、プレイヤーには**全部同質**に見える
- 音・光・ログ（ジュース）は**面白さの増幅器であって源ではない**
- 面白いタイピングゲーム（Typing of the Dead / 寿司打）は**打つ対象の側に構造がある**：どれを打つか・獲るか見送るか、の毎秒の意思決定

### 方向（オーナー壁打ちで確定）
面白さの源を 3 つ重ねる：**時限ボーナス（寿司打型）＋ フィーバー（音ゲー型）＋ バグ防衛（TD風）**。
選択制マルチターゲット（Typing of the Dead 型）は不採用。
画面は**ドット絵素材＋アニメーションでリッチに**（シンプルすぎは NG）。素材は PixelLab。

## 1. 新コアの画面設計（開発フェーズ）

```
┌────────────────────────────────────────────────┐
│ 出現レーン（コード帯の上を右→左にスプライトが流れる）              │
│   🐛(歩行アニメ)「ばぐたいじ」←──   💡(光る)「ひらめき」←──      │
├────────────────────────────────────────────────┤
│ メインライン：「れんさしょりをじっそうする」 renn|sasyori...      │
├────────────────────────────────────────────────┤
│ ノリ/フィーバーゲージ ▓▓▓▓▓░░ → MAX で 🔥FEVER（画面変化）      │
└────────────────────────────────────────────────┘
```

### 1-1. メインライン（従来の実装タイピング）
- 実装タスク文を打って進捗を積む（従来通り＋ノリ倍率）

### 1-2. 出現レーン（新規・面白さの源）
- **🐛 バグ虫**：ドット絵の虫が右から左へ這う。**左端到達で完成度がじわ減り（-2% 🔧）**。打てば取り返せる量＝詰まない（最上位の目的）
- **💡 ボーナス**：ひらめき玉等が流れ、数秒で消える。**取れたら品質/軸ボーナス、逃しても無罰**
- ボーナスとバグが同時に流れる瞬間＝**どちらを獲るかの判断**（選択の源）
- v0.14 のランダムイベント（天才のひらめき/ライバル出現…）は**特別な出現物**としてレーンに統合

### 1-3. 操作：Space でターゲット切替（確定）
- Space でメイン⇄出現物をトグル。**打ちかけのメイン文は保持され、位置ずれなし**
- 出現物の文を打ち切ると獲得/駆除（弾けるアニメ＋SE）→ メインへ自動復帰

### 1-4. フィーバー（確定：MAX で自動発動）
- ゲージは**正打で蓄積・ミスで減少**。MAX で自動発動（約 15 秒 🔧）
- 効果：進捗×2 ＋ ボーナス出現ラッシュ ＋ 画面変化（背景色・パーティクル）＋ SE
- 既存ノリ倍率（コンボ→×1.0〜2.0）と統合する 🔧（フィーバー中は上乗せ）

## 2. 最上位の目的整合（必ず守る）

- **時間切れ＝無罰**：ボーナスを逃してもマイナスなし。バグの侵食も「打てば取り返せる」量
- **詰みなし**：どれだけ放置しても完了不能にはならない（完成度は 0 未満にならない・侵食はバグ駆除で止まる）
- **タイピングが主役**：全要素（獲得・駆除・フィーバー維持）がタイピングで駆動

## 4. 数値（叩き台 🔧）

| 項目 | 叩き台 |
|---|---|
| バグ湧き間隔 | 10〜15 秒に 1 匹（進捗 50% 超で加速） |

| フィーバーゲージ | 正打 +1、ミス -20%、MAX=60 打 |

## 7. 変更履歴

### 2026-07-05（v0.15 初版）
- オーナー評価「面白くない。音は解決にならない」を受け、コア再設計を主題化
- 壁打ちで確定：B 時限ボーナス＋C フィーバー＋D バグ防衛（A 選択制は不採用）／Space 切替／完成度じわ減り／フィーバー MAX 自動発動／ドット絵リッチ画面（PixelLab）
- v0.14 のランダムイベントはレーン出現物に統合する方針

### 2026-07-05（レーン案 不採用 → ビルドアップ・タイピングへ転換）
- **レーン＋Space切替はプレイテストで不採用**（オーナー：「メインとサブをどれだけ打てばいいか分からない」「ボーナスレーンは全く面白くない」）
  - 学び：**1 画面に入力対象は 1 つ**。並行タスク管理はタイピングと両立しない
- オーナー要求を再定義：①**入力がどこに効くか見えること** ②**爽快感**
- 新コア「**ビルドアップ・タイピング**」で承認・実装：
  - 文＝属性つき開発作業（🎮面白さ/🎨グラフィック/🎵サウンド/📋企画力＋約12%で🐛バグ文）
  - 打ち切るとその属性の**開発パラメータが伸びる**（4 色バー・数字ポップ）＝因果の可視化
  - **数字インフレ**：基礎4 × コンボ段階（10:×1.5/30:×2/100:×3）× 速度判定（PERFECT×1.5/GREAT×1.2）× フィーバー×1.5
  - 次の作業プレビュー（属性チップ 3 個）／入力文は属性色の枠と文字
  - 開発パラメータはリリース時に品質へ合流（fun×0.12+graphics×0.08+sound×0.08+plan×0.05、叩き台 🔧）
  - フィーバーは存続（正打蓄積→MAX 自動発動 15 秒）
- 実機確認：「📋 企画力 +27 PERFECT! ×3」等のインフレ、4 属性バーの蓄積、FEVER 発動、1280×720 内に収まり（スクロールなし）
- PixelLab スプライト 3 点（バグ虫×2・電球）はレーン廃止に伴い**一旦保留**（バグ文の装飾等に転用余地）
