## Phase L1：共通骨格（固定ビューポート + 共通 HUD）

ターゲット：1280×720 固定で全画面を完結させる土台を作る。

  - `min-height: 100vh` → `width: 1280px; height: 720px` + `overflow: hidden`

- [x] **L1-2** `App.tsx` に `.game-root` ラッパを追加し、CSS transform で `scale(min(100vw/1280, 100vh/720))` を適用
  - PC 横ならそのまま 1280×720、スマホは縮小して両端に黒帯
- [x] **L1-3** `PixelStatusBar` に「📅 日付」+「次の週まで進捗バー」を統合（現在 OfficeScreen に置いてる）
  - 右側ゾーンに日付ラベル + 8px 高ゲージ
- [x] **L1-4** `PixelMenuBar` をフッタ位置で固定（84px）。OfficeScreen 以外でも常時表示

- [x] **L1-5** 各 Screen の構造を「ヘッダ HUD 56px + メイン 580px + フッタ 84px = 720px」に統一

## 実装順序の方針

1. **Phase L1（共通骨格）** を最優先 — これがないと他のフェーズが動かない
2. **Phase L2〜L7** は画面ごとに独立、優先順序は使用頻度（L2 → L3 → L4 → L5 → L6 → L7）
3. **Phase M（モーダル）** は L2〜L7 の各フェーズで使うので並行進行
4. **Phase A（素材手配）** は L1〜L7 の配置が固まった段階で着手
5. **Phase X（仕上げ）** は他フェーズ完了後
