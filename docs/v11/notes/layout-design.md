# v0.11 UI 刷新：固定ビューポート レイアウト設計

> 確定日: 2026-06-09
> 前提：素材（フォント・キャラ・家具・9-slice 等）は配置確定後に逆算
> ターゲット：**PC 横 1280×720** 基準、スマホは CSS transform でスケール
> 関連: [pixel-ui-research.md](./pixel-ui-research.md) / [ui-audit.md](./ui-audit.md) / [asset-definition.md](./asset-definition.md)

## 0. 設計原則

### 0-1. 固定ビューポート

```
ベース解像度: 1280 × 720 px（16:9）
スケーリング: CSS transform で .game-root を scale()
クリッピング: overflow: hidden で外側に出さない
```

ファミコン・スーファミ世代の据置ゲームと同じ思想：
**「ゲームは決まった画面サイズの中で完結する」**。

### 0-2. **スクロール全面禁止**

例外は以下のみ：
1. **作品ライブラリ**（リスト系、左右ページャ + 縦スクロール許可）
2. **チュートリアル長文ダイアログ**（ページャ送り）
3. **ジャンル相性図鑑**（タブで分割、ページャでめくる）

それ以外は **全部 1 画面で完結**。情報が入らなければ：
- フォントを 1 段階小さく
- セクションを統合
- モーダルで層を分ける

### 0-3. ゾーン分割の基本

```
┌─────────────────────────────────────────────────────────┐
│  ① ヘッダ HUD（資金・ファン・従業員・作品数）   高 56px       │
├─────────────────────────────────────────────────────────┤
│                                                          │
│                                                          │
│  ② メインコンテンツ（画面ごとに変わる）       高 580px      │
│                                                          │
│                                                          │
├─────────────────────────────────────────────────────────┤
│  ③ フッタメニュー（7 アイコン or 進行ボタン）   高 84px      │
└─────────────────────────────────────────────────────────┘
合計: 1280 × 720（56 + 580 + 84 = 720）
```

①ヘッダと③フッタは **全画面共通**で、main の中で各画面の固有 UI を組み立てる。

### 0-4. 安全領域

- 左右に **24px** の余白（外枠とコンテンツ間）
- main 内のセクション間は **12px**
- カードの中の padding は **8px or 12px**
- すべて **4px グリッド**に乗せる

### 4-3. ゾーン仕様

- 各セクション高さ 116px → 580px / 5 = 116px に収める
- ジャンル / テーマは横スクロール禁止、足りなければチップを 2 行折り返し（PixelMenuBar 風に）

### 5-3. ゾーン仕様

- **ヘッダ HUD**：日付 / 進捗バー / 経過秒
- **メインタイピング枠**：800×240、中央寄せ、現在の打鍵位置 + 次フレーズ
- **HUD**：コンボ / WPM / 精度
- **コンボゲージ**：横長フルバー
- **サイドパネル**：開発中に生成された「コード履歴」（過去打鍵 5〜10 行、固定高）
- **フッタメニュー**：**非表示**（タイピング集中、戻るボタンは ESC）

- フレーズ完走で次フレーズに自動繰り返し
- バグ発生時：バグフレーズが赤色でメインに割り込み
- 完了：時間到達で自動的に ReleaseScreen に遷移
- ESC キー：「開発中断確認」モーダル（中断ペナルティ 50% 損失）

### 5-5. トースト位置

- 画面右下に積み重ね（最大 3 件）
- 各 2 秒で自動消去
- バグ発生 / WPM ブレイク / 月固定費発生 等

## 11. 縮小スマホ対応（横画面 / 縦画面）

.game-root {
  width: 1280px;
  height: 720px;
  transform: scale(calc(min(100vw / 1280, 100vh / 720)));
