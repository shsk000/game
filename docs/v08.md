## 0. 事業目的と前提（最重要・確定事項）

本プロジェクトは**リアルマネーの収益化を目的**とする。面白さは目的そのものであると同時に、収益を生む土台でもある。この2つは対立しない――**長く遊ぶユーザーが結局一番広告を見る**から、「面白くて続く」設計が「稼げる」設計と一致する。

### 収益化の基本方針（確定）
- **収益手段は当面「広告」に一本化。** 課金は将来的な拡張候補として設計に余地を残すが、当面は実装しない。
- **広告はリワード（任意視聴）を主役にする。** ユーザーが「自分から見たくなる」「見たほうがゲームを進めやすい」状態を作るのが最優先。
- **強制広告（インタースティシャル）は区切りでたまに挟む程度に留める。** 主役はあくまでリワード。強制は補助的な収入源。
- **大原則：広告を「進行の人質」にしない。** 自力でもクリアできる難易度を保ち、広告は「見ればさらに楽・得」になる位置に置く。嫌々見せる広告は離脱を生み、離脱したユーザーは二度と広告を見ない。

### 広告の3分類（本資料で使う語彙）
| 種類 | 見せ方 | ユーザー体感 | 本作での扱い |
|---|---|---|---|
| **リワード広告** | 任意。見ると報酬 | 自分から見る・好かれる | ◎ 主役 |
| **インタースティシャル** | 強制。区切りで全画面 | 邪魔だが許容範囲なら可 | △ 区切りでたまに |
| **バナー** | 常時表示 | 気にならないが単価低い | ○ 補助収入（任意） |

### プレイ環境（確定）
- **PC横画面を優先。物理キーボードでの高速タイピングを前提とする。**
- これにより、本格的な打鍵の歯ごたえ・WPM・長文コードを主役にできる（スマホのフリック入力では成立しない設計を選べる）。
- スマホ対応は当面スコープ外（将来検討）。

### 進め方（確定）
- 決定事項は都度この資料に反映し、最終的な実装の元仕様とする。
- 判断に迷う箇所はプロデューサー（Claude）が論点を整理して提示し、方針はオーナー（shsk）が決定する。

## 1. コンセプト

プレイヤーはインディーゲーム会社の社長。自分でコードを打つ（タイピング）ことが開発作業そのもの。**制限時間（締切）はない。** 代わりに、必要コード量を打ち切るまでの**実時間（開発タイム）が計測**され、速く打つほど早く完成する。完成後は**任意で好きなだけ打って品質を磨ける（ポリッシュ）**。

タイピングが遅くても失敗はしない（誰も弾かれない）。速い人は記録を狙い、磨きたい人はとことん磨く。緊張感は「制限時間に追われる」のではなく、**過去の自分（ゴースト）やライバルを超える**という前向きな形で与える。

**設計思想：タイピングの速さ・正確さが、開発タイムと品質に直接変換される。誰も弾かず、上達がそのまま結果になる。タイピングは最後まで主役。**

## 2. 中核ループ（経過時間が主役）

```
作品を企画（ジャンル×テーマを選ぶ）
        ↓
【開発フェーズ】必要コード量を打ち切れ（制限時間なし・自ペース）
   かかった実時間 = 開発タイム（速いほど良い記録）
   打つ速さ = 自分のタイピング速度 ＋ 社員の自動生産
   ★ 過去最速の「ゴースト」が並走 → 追い抜く緊張
        ↓
必要量に到達 = 完成（品質：最低保証）
        ↓
【ポリッシュフェーズ】任意で追加タイピング → 打った量だけ品質UP
   やめどきは自分で決める（速く終えた人ほど磨く余力がある）
        ↓
リリース → 品質スコア × 企画相性 × トレンド で売上決定
        ↓
売上を投資（社員雇用 / 設備 / 新ジャンル解放）→ もっと大きい作品へ
```

### プレイヤーごとの楽しみ方
- **速さ重視** → 開発タイムを縮め、ゴースト/ライバルに勝つ。記録更新の快感
- **品質重視** → さっと完成させ、ポリッシュでとことん磨いて高売上
- **どちらも** → 速く完成＋たっぷり磨く＝最高効率（上達のご褒美）

## 3. すべてが「タイピングの腕」に変換される

| 要素 | 役割 |
|---|---|
| **タイピング速度（WPM）** | 速いほど開発タイムが短い＝良い記録／磨く余力も増える |
| **正確さ（ノーミス）** | ミスはやり直しで時間ロス。バグ混入で品質減 |
| **コンボ／ノリゲージ** | ミスなく速く打ち続けると倍率UP。途切れると惜しい（前向きな緊張） |
| **自動生産（社員）** | 自分と並行してコードを積む＝開発タイム短縮の恒常的な底上げ |
| **ゴースト** | 過去最速タイムが並走。追い抜く目標＝失敗なしの緊張 |
| **品質** | ポリッシュで打った量に応じて上昇＝売上に直結 |
| **広告：開発加速** | この作品だけ生産2倍＝開発タイムを縮める |
| **広告：ポリッシュ効率** | ポリッシュの品質上昇を一時2倍＝同じ打鍵で高品質 |

## 4. 品質ポリッシュの仕組み【本作の肝・方式B】

開発フェーズで必要コード量に到達したら完成（品質は最低保証）。そこから**任意で**、好きなだけ追加コードを打てる。打てば打つほど品質スコアが上がる。**やめどきはプレイヤーが決める。**

```
[開発] 必要コード量に到達 ──→ 完成（品質：最低保証）
                                  ↓ 任意で…
[ポリッシュ] 打鍵 = 演出追加・バグ修正・調整
                  打った量に比例して品質スコア上昇
                                  ↓ プレイヤーが「リリース」を押す
                            最終品質確定 → 売上
```

- **速く打てる人** → 早く完成 → ポリッシュの余力たっぷり → 高品質 → 高売上
- **じっくり磨きたい人** → 完成後とことん打って高品質
- **広告を使う人** → 開発加速/ポリッシュ効率2倍で時短・底上げ

→ タイピング上達のご褒美が「開発タイム短縮」と「高品質＝高売上」の両方で返ってくる。最後の一打までタイピングが主役。

## 4-G. 前向きな緊張の設計（ゴースト＆ライバル）【確定】

制限時間を無くした代わりに、「失敗のプレッシャー」ではなく「**超えると気持ちいい**」緊張を入れる。初心者を弾かず、上級者を燃えさせる。

### ゴースト（自己ベストとの競争）
- 同じ作品規模での**自分の過去最速タイム**がゴーストとして並走
- 開発中、ゴーストとの差をリアルタイム表示（「ゴーストより+2.3秒速い！」）
- 抜けば記録更新＝演出＋実績。負けても何のペナルティもない
- レースゲームの手法。失敗がないのに熱くなる中核

### ライバル会社（外部との競争・スパイス）
- 「ライバルが同じジャンルを開発中。先にリリースすると話題を独占＝売上ボーナス」
- 負けても破滅しない（売上が標準に戻るだけ）。勝つと嬉しい、の設計
- トレンドと絡めて「今この組合せはライバルも狙っている」と煽る

### ノリゲージ（連続の緊張）
- ミスなく速く打ち続けると「ノリ」ゲージが上昇 → 打鍵効率・品質にボーナス
- ミスすると途切れて「惜しい」。途切れない緊張が集中を生む
- これは制限時間なしでも成立する、純粋にタイピングの質への報酬

> いずれも「間に合わないと失敗」ではなく「超えると得・気持ちいい」。収益目的（初心者を弾かず母数を増やす）とも噛み合う。

## 4-H. 評価システム ―― 「どれぐらい面白いものができたか」を見せる【確定：メタスコア中心】

作品の出来を、開発中の「予感」と完成後の「評価」の2段階で見せる。**主役は0〜100のメタスコア**（憧れの数字）。

### 開発中：リアルタイムの手応え（予感）
打っている最中から、作品がどう転びそうか分かる。

- **品質メーター**：ポリッシュで打つほど伸びるバー（今 Q60 など可視化）
- **期待度の予感**：「ジャンル相性 × トレンド × 品質」で、開発中から「これは跳ねそう…」が見える
- **手応え演出**：好相性＋ノリ継続だと画面が盛り上がる（「開発が乗ってる！」）、悪相性だと地味
- これにより、リリース前から「今回は傑作の予感」「微妙かも」が体感できる

### 完成後：メタスコアの開示（評価）
リリース後、**メタスコア（0〜100）**が演出付きで発表される。これが中毒の核＝ガチャを開ける瞬間。

```
メタスコア = f(品質Q, ジャンル相性, トレンド合致) ＋ 変動（±数点のブレ）🔧
```
- **変動（ブレ）が中毒の肝**：同じ作りでも毎回±数点ぶれる → 「90点台が出るか！？」のドキドキ
- **たまに大当たり**：ごく低確率で大幅プラス補正＝「神ゲー認定」（バイラルヒット演出）🔧
- **スコア帯ごとのフレーバーレビュー**（補助）：
  - 90+：「今年の傑作」「殿堂入り級」
  - 70〜89：「良作」「次に期待」
  - 50〜69：「平凡」「惜しい」
  - 〜49：「バグだらけ」「企画倒れ」

### 評価が次につながる（メタ進行と接続）
評価は結果で終わらず、次回作を有利にする。

- **ファン数**：高メタスコアでファンが増える → 次回作の初動（初週販売）を底上げ
- **会社の名声**：累積で上がり、受注できる作品規模やトレンド察知力に影響🔧
- **記録**：自己最高メタスコアが殿堂に記録（メタ進行・柱3）
- → 「もっと高いスコアを出したい」が次のプレイを回す

## 4-I. 販売・資金化システム ―― 売って資金にする【確定：放置でジワ売れ】

売上を「一瞬で確定」ではなく「**しばらく売れ続ける**」形にする。離れている間も資金が貯まり、戻る理由になる（放置ゲーらしさ）。

### 販売の流れ
```
リリース
  ↓
【初動】初週販売 = メタスコア × ファン数 × 作品規模 で決定🔧
  ↓
【販売期間】数日（実時間 or ターン）かけてジワジワ売れる ← 放置で資金が貯まる
  ├─ 高メタスコアなら口コミで販売が伸びる（売れ行き加速）
  ├─ ローンチ広告（リワード）で初動ブースト ← 収益ポイント
  ├─ トレンド合致なら期間中ボーナス
  └─ ロングテール：名作ほど長く売れ続ける
  ↓
【売上確定】資金に加算 → 経営ターンで社員/設備に投資
```

### メタスコアと放置報酬の連鎖（設計の肝）
**高メタスコア → 長く売れ続ける → 戻るたびに資金が増えている。** 良い作品を作る動機が、放置報酬の大きさに直結する。「いい物を作る」と「放置で儲かる」が一本につながる。

### 売上計算（4-Iと7-Eを統合）🔧
```
総売上 ¥ = Σ(日次販売) 
日次販売 = 基礎単価 × 作品規模 × (メタスコア/50) × 口コミ係数 × トレンド係数
口コミ係数 = メタスコアが高いほど減衰が遅い（名作はロングテール）
```

### 複数作品の同時販売（中盤以降）
- 過去作も販売期間中なら売れ続ける → 「複数の収入源」を抱える経営感
- ヒット作のロングテール＋新作の初動が重なると資金が一気に伸びる
- これが「会社が育つ」実感（メタ進行・柱1）を強化

### 広告接続
- **ローンチ広告**（リワード）：初動 ×1.5。リリース直後の「もっと売りたい」に刺さる
- **再訪時オフライン報酬**：離席中の販売を広告で2倍

> 🔧：初週販売式・口コミ減衰カーブ・販売期間の長さ・変動幅は、紙の初期値→プロトで調整。

## 5. 難易度＝作品規模（必要コード量で表現）

作りたいゲームが大きいほど必要コード量が増える＝**打つ量が増え、手が忙しくなる**。制限時間はないので「詰む」ことはなく、大作ほど開発タイムが長くなる（その分ゴースト更新の幅も大きい）。

> **基準（確定）**：1作あたりのプレイは**テンポ重視＝数十秒〜数分**。短いループの反復でプレイ回数を増やし、広告接触機会を最大化する。

| 作品規模 | 必要コード量 | 標準的な開発タイム目安🔧 | 体感 |
|---|---|---|---|
| ミニゲーム | 少 | 〜30秒 | 練習・チュートリアル |
| スマホゲーム | 中 | 〜1分 | ちょうどいい歯ごたえ |
| インディー大作 | 多 | 〜1.5分 | 集中必要・広告が刺さり出す |
| 話題作 | 激多 | 〜2分 | 全力タイピング |
| AAAタイトル | 鬼 | 〜3分 | 全力＋社員/広告で時短 |

**重要：** 自動化が進んでも、より大きい作品に挑めば手で打つ量はまた増える。「自動化したから楽」ではなく「自動化したぶん、もっと上を狙える」。上達した人ほど上の規模に挑め、そこには相応の打鍵量が待つ。**タイピングは決して卒業させられない。**

## 6. 広告設計（収益の中核）

> 全体方針は「0. 事業目的」に準拠：**リワード主体＋区切りで強制をたまに**。本セクションは具体的な配置を定義する。

### 大原則
広告（特にリワード）は **「開発タイムを縮める／品質を底上げする」任意の加速装置**。
本筋（タイピング＋社員）だけでも全規模クリア可能な設計を保ち、広告は「自力でも進めるが、見ればさらに速く・高品質になる」位置に置く。広告を進行の人質にする設計（＝見ないと進めない）は禁止。

### 加速手段は3段階
1. **本筋：タイピングの上達**（自分が速くなる＝開発タイム短縮）
2. **恒常：社員/設備の自動生産**（経営の成果としての底上げ）
3. **その場：広告**（開発加速・ポリッシュ効率・売上ブースト）

### 6-1. リワード広告（任意・主役）が自然に刺さる瞬間

ユーザーが「自分から見たい」と思う＝**見れば明確に得をする**場面に置く。

| タイミング | 見せ方 | プレイヤー心理 |
|---|---|---|
| 開発が長引いている | 広告で「クランチ稼働」＝この作品の生産2倍（開発タイム短縮） | 早く完成させたい |
| ゴースト/ライバルに負けそう | 広告で一時加速＝記録更新を狙える | 勝ちたい |
| ポリッシュ中 | 広告でポリッシュ効率2倍＝同じ打鍵で高品質 | 売上を伸ばしたい |
| リリース直後 | 広告で「ローンチ広告キャンペーン」＝売上+50% | 売上を伸ばしたい |
| 再訪時 | 離席中に社員が進めた開発成果を広告で2倍 | 戻ってきた瞬間の得 |
| 未知の組合せに挑む時 | 広告で「市場調査」＝相性を事前に一部開示／最低売上保証 | リスクを抑えたい |

特に「**広告を見て広告キャンペーンを打つ**」はテーマ的にハマる。

### 6-2. 強制広告（インタースティシャル・補助）の配置

主役はリワード。強制は「区切りでたまに」に留め、テンポを壊さない位置に置く。**プレイの集中（タイピング中）を絶対に遮らない**のが鉄則。

- **配置候補**：ステージ（会社の成長段階）クリア時／一定本数リリースごと（例：3本に1回）／長時間プレイの自然な切れ目
- **頻度上限の目安**：体感で「邪魔」と感じさせない範囲（例：数分に1回を超えない、リリース直後の結果表示の後など"手を止めている"瞬間に限定）
- **禁止**：開発フェーズ中・タイピング中・ポリッシュ中の割り込み。集中の最中に挟むと最悪の体験になる

### 6-3. 収益と体験の両立チェックリスト（実装時に守る）
- リワードは「見れば得」、強制は「テンポを壊さない切れ目だけ」
- 広告を見なくてもクリアは可能（人質化しない）
- 広告視聴の**完了コールバック後**に報酬付与（スキップ・在庫なし・ブロッカーのフォールバック必須）
- 1セッションあたりの強制広告回数に上限を設ける

## 6-5. コアループ詳細 ―― 7ステップで何をどう遊ぶか（確定方針）

> 1作（1周）は数分。この7ステップが「気持ちいい操作」を担当し、後述のメタ進行が「やめられない理由」を担当する。**二層構造が中毒性の正体。**

### ① 作るゲームを計画する
- **画面**：次作の「ジャンル × テーマ」を選ぶ（2〜3スロット、数秒で完了）
- **操作**：スロットをタップ/クリックで選択
- **楽しさ**：組合せの発見。相性◎なら大ヒットの予感、未知の組合せはギャンブル
- **飽きさせない仕掛け**：
  - 最初はジャンル3種だけ → プレイで新ジャンル・新テーマがアンロック
  - 初めて作る組合せに「新規開拓ボーナス」
  - 「この組合せが今バズってる」のトレンド提示で毎回状況が変わる
- ※ジャンル相性は本作の面白さの柱（詳細は「6-7. ジャンル相性システム」）

### ② 実装する（タイピング）＝主役
- **画面**：経過時間（開発タイム）が刻まれる中、表示コードを打つ。**過去最速のゴーストが並走**
- **操作**：物理キーボードで高速タイピング（PC前提）
- **楽しさ**：自ペースで打てる安心感＋ゴースト/ライバルを追う前向きな緊張＋打鍵の手応え＋ノリゲージの伸び
- **飽きさせない仕掛け**：
  - 打つコードが選んだジャンルで変わる（ホラー＝不気味な変数名、寿司＝和風の関数名）
  - 経過タイム・ゴースト差・ノリゲージのリアルタイム表示で「今ノってる／勝ってる」感
  - たまにバグイベント（赤い行→素早く打ち直すと高ボーナス）等の変化球

### ③ 完成
- **瞬間**：必要コード量に到達 → 「完成！」演出＋開発タイム確定（ゴースト更新ならファンファーレ）
- **楽しさ**：達成感の爆発。続けて**任意でポリッシュ**へ（方式B）
- **飽きさせない仕掛け**：完成演出＋「磨くほど高品質！」の誘い。品質バーが目に見えて伸びる。やめどきは自分で決める

### ④ 出荷（リリース）
- **瞬間**：ポリッシュを切り上げてリリース → 作品が世に出る
- **楽しさ**：評価される直前のドキドキ
- **飽きさせない仕掛け**：
  - リリース時「ローンチ広告を打つ？（リワード広告で売上+50%）」← 収益ポイント
  - 作品がライブラリに永久保存（コレクション）

### ⑤ 世間の評価が決まる（詳細：4-H）
- **画面**：メタスコア（0〜100）が演出付きで開示。レビュー文・ファン増減も
- **楽しさ**：ガチャを開ける瞬間の快感。スコアの変動（ブレ）＝**変動報酬＝中毒の核**
- **飽きさせない仕掛け**：
  - スコア帯ごとのフレーバーレビュー（「今年の傑作」「バグだらけ」）
  - たまに大当たり（「神ゲー認定」で大幅プラス）
  - 自己最高メタスコア更新で実績・殿堂入り

### ⑥ 利益につながる（詳細：4-I）
- **瞬間**：作品が販売期間に入り、放置でジワジワ売れて資金が貯まる
- **楽しさ**：高メタスコアほど長く売れる＝戻るたび資金増の連鎖。桁が増える快感
- **飽きさせない仕掛け**：複数作品の同時販売、ロングテール、「あと¥◯◯で新オフィス！」と次の目標が常に見える

### ⑦ 経営ターン（人材確保・強化）
- **画面**：資金で社員雇用・設備投資・アンロック
- **楽しさ**：自分の会社をビルドする戦略性。次周が強くなる準備
- **飽きさせない仕掛け**：
  - 社員に個性（速いが雑／遅いが高品質）→ 編成の悩み
  - 「次は何を解放するか」の投資判断
  - **ここに強制広告（インタースティシャル）を配置**（ターンの切れ目＝手が止まる瞬間）

## 6-6. メタ進行 ―― 1〜2ヶ月続く中毒性の設計（確定：3本柱バランス型）

> 1周は数分で終わる。何百周もさせる燃料は「周をまたいで蓄積するもの」。**経営・コレクション・記録の3本柱をバランスよく**走らせる。

### 柱1：会社が育つ（経営）
- 資金・社員・設備・オフィスが永続的に強化される
- 「あと少しで次のオフィス／次の人材」が常に見える＝目標の連鎖
- 数字（累計売上・会社規模）が桁を増やしていく放置的快感

### 柱2：コレクションが埋まる
- **作品ライブラリ**：作ったゲームが全て資産として残る
- **ジャンル組合せ図鑑**：発見した「ジャンル×テーマ」の相性を埋めていく（本作の柱と直結）
- **実績・称号**：「初の神ゲー」「ゴースト大幅更新」「炎上経験」など

### 柱3：記録が伸びる（やり込み）
- 最速完成タイム、最高品質スコア、最高売上、連続ヒット記録、最高WPM・最高コンボ
- 「先週の自分」を超える動機。タイピングゲームと相性最高
- 記録更新時に演出＋実績

### 3本柱を破綻させない設計方針
- 序盤は柱1（経営の成長実感）を前面に → 触ってすぐ伸びる手応え
- 中盤から柱2（コレクション）が効き始める → 「あの組合せまだ作ってない」
- 長期は柱3（記録）がエンドコンテンツ → やり込み層を維持
- **常にどれか1つは"あと少しで達成"の状態**を作る（ツァイガルニク効果）

## 6-7. ジャンル相性システム ―― 面白さの柱（確定：深掘り）

> 「ジャンル×テーマの組合せ」を本作の面白さの中心に据える。発見・図鑑・トレンドで奥行きを出す。

### 基本構造
- **ジャンル**（例：ローグライク、RPG、パズル、レース、ホラー…）
- **テーマ**（例：寿司、宇宙、忍者、農業、恋愛…）
- 1作 = ジャンル1つ × テーマ1つ（将来的に複数掛けも検討）

### 相性（隠しパラメータ → 発見して図鑑化）
- 各組合せに隠れた相性値（売上の企画ボーナス 0.7〜2.0倍）
- **初めて作るまで相性は不明**＝開拓のワクワク
- 一度作ると図鑑に記録され、以降は相性が見える＝知識の蓄積
- 「神の組合せ」（隠れた当たり）を探す楽しみ

### 飽きさせない追加レイヤー
- **トレンド**：今流行のジャンル/テーマに合致で売上ボーナス（毎回変動＝変動報酬）
- **新規開拓ボーナス**：初組合せに一時ボーナス → 網羅したくなる
- **アンロック**：プレイでジャンル・テーマが増え、組合せ空間が拡大し続ける
- **シナジー演出**：好相性だと「開発が乗ってる」演出、悪相性だと苦戦演出

### 収益との接続
- 「この組合せ、相性良さそうだけど未知…広告でリスク保険（最低売上保証）」など、相性のギャンブル性を広告動機に転換できる🔧

|---|---|

例：「ホラー×温泉」「レース×寿司」「RPG×コンビニ」のような掛け合わせで意外性を出す。

### A-3. 相性システム（本作の柱）

- 各「ジャンル×テーマ」に**隠れた相性値**を持たせる（企画ボーナス 0.7〜2.0倍）🔧
- **初めて作るまで相性は非公開**。作って初めて図鑑に記録され、以降は可視化
- 相性のランク表示例：💀地雷(0.7) / 😐普通(1.0) / 👍good(1.3) / 🔥神(1.7+)
- **「神の組合せ」は全体の数%だけ**仕込む＝探索のロマン🔧

#### 相性値の決め方（設計ルール）
机上で全組合せ（12×15=180通り）を手で決めるのは非現実的なので、**ルールベース＋手動の当たり指定**で生成する：
1. ベース1.0
2. ジャンルとテーマに「タグ」を持たせ、タグの相性で加減算（例：ホラー＝怖い系、ゾンビ＝怖い系 → 一致でボーナス）🔧
3. 開発者が**手動で「神の組合せ」を10〜20個**指定（ネタ的に面白いもの）
4. ごく一部に**地雷**を仕込む（学習要素）

### A-4. アンロック設計（飽きさせない供給）

- 序盤：ジャンル3＋テーマ5でスタート（組合せ15通り＝すぐ一巡しない量）
- リリース本数 or ステージ進行で**ジャンル/テーマを小出しに解放**
- 解放のたびに「新しい組合せ空間」が一気に広がる＝探索欲の再点火
- **新規組合せ初回ボーナス**で「まだ作ってないやつ」を作りたくさせる

### A-5. トレンド（変動報酬）

- 一定間隔で「今月のトレンド」が変動（例：今はローグライクが流行 / 寿司テーマがバズり中）🔧
- トレンド合致で売上ボーナス（×1.5など）、逆張りは不利
- 再訪のたびに状況が変わる＝戻る理由＋毎回違う判断
- **「トレンド × 高相性 × 高品質」が揃うと特大ヒット** → 狙って当てる快感

### A-6. 図鑑（コレクション＝メタ進行の柱2に接続）

- 発見した組合せが図鑑に記録（相性ランク・最高品質・最高売上を保存）
- 「未発見の組合せがあと◯個」で網羅欲を刺激
- 全マス埋め・神の組合せ全発見などで実績解除

> 🔧：相性値・トレンド頻度・神/地雷の割合は、紙の上で初期値を置き、後でバランス調整する。次の作業（付録B：タイピングで打つ内容）で、ジャンルごとの打鍵テキストを具体化する。

## 付録A-V. 作品ビジュアルの組み合わせ生成 ―― 「作った作品が見える」【確定：面白さの本体】

> **重要な設計判断**：作った作品を「テキストと数字」だけで表すのは魅力を殺す。Game Dev Storyが面白いのは、作品に絵・タイトル・ジャケットがあるから。作品が**見える形で存在**してこそ、コレクション欲・達成感・「自分が作った」感が生まれる。素材は「コスト」ではなく「面白さの本体の一部」。

### 基本方針：少ない素材で無限に見える化する
固定の完成品を大量に用意するのではなく、**パーツの組み合わせで作品ビジュアルを自動合成**する。

```
作品ジャケット = 背景（ジャンルで決定）＋ シンボル（テーマで決定）＋ 自動生成タイトル
```
- ジャンル12種ぶんの「背景パーツ」＋テーマ15種ぶんの「シンボルパーツ」を用意するだけで、12×15=180通りのジャケットが組み合わせで生まれる
- 作るたびに違う見た目の作品ができる＝図鑑・ライブラリが映える

### スタイル（確定）：ドット絵／レトロ調
- 低解像度ゆえAI生成のアラが目立たない（粗さが味になる）
- 「ゲーム会社経営」のテーマと世界観が合致（レトロゲーム時代の空気）
- 組み合わせ合成と相性最高（パーツを重ねても破綻しにくい）、安価で量産可能

### 自動タイトル生成（素材ゼロで個性を出す）
- 「ジャンル×テーマ」からタイトルをテキスト合成
  - 例：「ホラー×温泉」→「呪いの大浴場」／「レース×寿司」→「爆走！回転寿司GP」
- 単語テーブル＋テンプレートの組み合わせで生成（ロジックのみ、素材不要）
- ネタ感のあるタイトルが量産され、トーン（現実＋ネタ）にも合う

### 合成で見せる対象
- 作品ジャケット（ライブラリ・図鑑・販売画面で表示）
- 社員アバター（パーツ組み合わせ：顔・髪・服など）🔧
- オフィスの見た目（成長段階で変化）🔧

## 付録Z. 制作リソース方針 ―― 素材の作り方（実装フェーズ用・詳細）

> 収益化が目的のため、**素材のライセンスは最初から厳密に**。後から「商用NGだった」は致命傷。以下はツール選定・ライセンス・ワークフローの指針。**情報は2026年時点。AI生成と著作権の状況は変化が速いため、実装着手時に最新の規約を再確認すること。**

### Z-1. スタイルと調達方針（確定）
- スタイル：**ドット絵／レトロ調**
- 調達：**AI画像生成でパーツを生成 → ピクセルエディタで人間が加工・調整 → 組み合わせ合成**

### Z-2. ツール候補（2026年時点）🔧
| 用途 | 候補 | 備考 |
|---|---|---|
| ドット絵AI生成 | Sprite AI 等のゲーム特化ツール | エンジン想定サイズ（16×16〜128×128）で生成、スプライトシート書き出し、商用ライセンス付き有料プランあり |
| 手描き・加工 | Aseprite（買い切り）/ Piskel（無料） | AI出力の仕上げ・微調整の定番 |
| 効果音 | 効果音ラボ（日本語・商用可）/ freesound / OpenGameArt | ライセンス条件は各素材ごとに要確認 |
| UI | CSS/コードで描画 | ボタン・メーター・パネルは画像不要が最速 |

### Z-3. 推奨ワークフロー（品質と権利の両立）
1. AIでパーツのバリエーションを多めに生成（例：1パーツにつき複数案）
2. 良いものを選別
3. **ピクセルエディタで人間が加工・調整**（色調整・パレット統一・トリミング）
4. 組み合わせ合成のパーツとして組み込む

→ プロが実際に使う「AIで下書き大量生成→選別→エディタで仕上げ」の王道。大量のアイコン/バリエーションを効率的に揃えられる。

### Z-4. ライセンス上の重要な注意（2026年時点）⚠️
- **純粋なAI生成物（プロンプトのみ）は著作権保護の対象外**という米国当局・判例の流れがある。つまりAI生成しっぱなしの素材は「自社の著作物」として保護されにくい＝他者の模倣を法的に止めにくい。
- **対策**：AI出力の上に**人間の創作的加工を加える**ことで保護を組み込める。上記Z-3のワークフロー（加工を必ず一手間入れる）はこの観点でも正しい。
- **使用ツールは「商用ライセンス」を明記した有料プランを選ぶ**。生成物の商用利用可否はサービスの規約で決まるため。
- 無料素材（効果音含む）も**商用可・クレジット要否**を素材単位で確認し、記録を残す。
- AIアートの販売・商用利用自体は多くの法域で合法。問題になるのは著作権の曖昧さとプラットフォーム規約。**規約の確認と人間加工が事実上の保護**になる。

### Z-5. 段階的な作り込み方針
- **初期（プロト）**：UIはCSS、作品ジャケは背景色＋絵文字シンボルの簡易合成、効果音なし でも成立させる → ロジック実装に集中
- **磨き込み期**：AI生成ドット絵パーツに差し替え、効果音追加、社員アバター・オフィス見た目を実装
- → 「面白いと確認してから絵を作り込む」。ただし作品が見える仕組み自体は最初から入れる（テキストだけにしない）

## 7. 経営の面白さ（開発の合間の判断）

タイピング（速さと品質の追求）が主役。その合間に経営判断で変化と奥行きを出す。
（※詳細は「6-5 ⑦経営ターン」「6-6 メタ進行」「付録A」を参照。以下は補足）

### A. ジャンルの掛け合わせ【メイン】
- 作品ごとに「ジャンル × テーマ」を選ぶ／組み合わせる（例：「ホラー×料理」「農業×ローグライク」）
- 珍しい組み合わせほどハイリスク・ハイリターン
- 作品はライブラリに残り、コレクション欲を刺激
- 戦略：「勝負作は自分で全力タイピングして高品質」「量産作は広告で楽に標準品質」を使い分け

### B. 市場・トレンド読み【スパイス】
- 流行ジャンルが変動。流行に張ると売上ボーナス、逆張りはリスク
- "市場速報"の形で再訪のたびに状況が変わる＝変動報酬の役割

### C. 社員育成・組織づくり【スパイス】
- プログラマー（自動生産）／デザイナー（品質ベースUP）／広報（売上UP）など職種
- 誰を雇うかで会社の強みが変わる。終盤は複数ライン並行へ

## 7-E. 経済設計（叩き台 v1 ／ 要検証）

> 収益化の生命線。「広告を見ると得する」の"得"が弱いと誰も見ず、強すぎると無料で進みすぎて成立しない。このさじ加減を数値で定義する。**以下の数値は叩き台であり、実機テストで調整する前提（🔧＝要検証）。**

### 基本単位
- **コード量（LoC）**：作品を完成させるために打つ量。タイピング1回の成功＝数LoC
- **資金（¥）**：ゲーム内通貨。作品リリースで得る。社員雇用・設備に使う
- **品質スコア（Q）**：0〜100。完成時の最低保証＋ポリッシュで上昇

### 作品規模ごとの数値（叩き台）🔧
| 規模 | 必要LoC | 標準開発タイム目安 | 完成時の最低Q | 想定プレイ時間 |
|---|---|---|---|---|
| ミニゲーム | 80 | 〜30秒 | 30 | 〜40秒 |
| スマホゲーム | 200 | 〜50秒 | 35 | 〜1分 |
| インディー大作 | 500 | 〜80秒 | 40 | 〜1.5分 |
| 話題作 | 1,000 | 〜120秒 | 45 | 〜2分 |
| AAA | 2,000 | 〜180秒 | 50 | 〜3分 |

※開発タイムは「標準的な腕」での目安。速い人はこれより短縮でき、それがゴースト記録・高評価につながる。制限時間ではない。テンポ重視のため上位規模でも1作3分以内に収まる量にする。

### 売上計算式（叩き台）🔧
```
売上 ¥ = 基礎単価 × 必要LoC × (品質スコア Q / 50) × 企画ボーナス × トレンド係数
```
- **品質Qが50で等倍**。50未満は減収、50超は増収 → ポリッシュで打つ動機
- **企画ボーナス**：ジャンル×テーマの相性（0.7〜2.0倍。珍しい組合せはハイリスク・ハイリターン）🔧
- **トレンド係数**：流行に合致で1.5倍、逆張りで0.7倍など🔧

### ポリッシュの品質上昇（叩き台）🔧
```
最終Q = 最低保証Q + (ポリッシュで打ったLoC × ポリッシュ係数)
上限 Q = 100
```
- 例：ポリッシュ係数 = 0.1（10LoC打つごとにQ+1）
- 開発を速く終えた人ほど時間に余裕があり、好きなだけ磨ける＝高売上
- やめどきは自分次第。Q上昇は逓減カーブにして「どこで切り上げるか」の判断を生む🔧

### 広告の効果（叩き台）🔧
| 広告 | 効果 | 数値（仮） |
|---|---|---|
| 開発加速 | この作品の生産速度 ×2（開発タイム短縮） | 30秒間 |
| ポリッシュ効率 | ポリッシュのQ上昇 ×2 | 30秒間 |
| ローンチ広告 | リリース売上 ×1.5 | リリース直後1回 |
| オフライン2倍 | 離席中の自動生産 ×2 | 再訪時1回 |
| 市場調査 | 未知組合せの相性を一部開示／最低売上保証 | 企画時1回 |

**広告1回の価値の目安**：自力プレイ十数秒〜数十秒ぶんの短縮・上乗せ。「見れば明確に得だが、見なくても進める」範囲に収める🔧

### 経済バランスの原則（実装で守る）
1. **広告なしでも全規模クリア可能**（人質化しない）
2. **広告ありだと体感1.3〜2倍お得**（見たくなる強さ、でも壊れない）
3. **資金インフレを管理**：上位規模ほど売上は増えるが、社員/設備コストも指数的に上げて青天井を防ぐ🔧
4. **テンポ維持**：1作の完結を数十秒〜数分に保つ

> 🔧 のついた数値は、プロトで実際に打って「気持ちよさ」と「広告を見たくなる強さ」を確かめながら確定する。

## 9. 続けたくなる心理メカニズム（リテンション）

実装優先度つき。効果が高く軽いものから。

### コア（最初に入れる）
1. **ゴースト/ライバルとの競争** ── 「過去の自分を超える」前向きな緊張が中毒源。本作固有の強み
2. **変動つきオフライン報酬** ── 離席中の社員の成果＋たまに大当たり。戻る理由
3. **成長の可視化** ── WPM・最高コンボ・最高品質スコアの記録。「先週より速い／高品質」が燃料

### 中盤以降
4. **実績・称号** ── 「初リリース」「ゴースト大幅更新」「100コンボ」などコレクション欲
5. **作品ライブラリ** ── 作品が資産として残る

### 当面入れない（離脱リスク）
- スタミナ制限、「腐る」プレッシャー系 ── 楽しむ前に義務感を生む

## 10. 技術メモ

- **形態**：ブラウザゲーム（HTML5）。PCネイティブ（Steam等）は広告規約・SDK面で不向き
- **実装**：React or 素のJS + requestAnimationFrame。経過時間計測とゴースト記録の保存が中核
- **タイピング判定**：日本語対応ならローマ字の複数許容（「し」＝`shi`/`si`）。英字＋プログラミング用語なら判定は単純
- **時間管理の肝**：開発タイム計測、ゴースト（自己ベスト）の保存と並走表示、必要コード量への到達判定、ポリッシュの品質加算、広告による加速の反映
- **広告SDK候補**：Google H5 Games Ads（`adBreak()`/`adConfig()`）／ポータル配信（CrazyGames・Poki・GameMonetize）
- **広告実装の鉄則**：視聴完了コールバックを受けてから効果付与。スキップ・在庫なし・広告ブロッカーのフォールバック必須
- **セーブ**：localStorage（離席時刻を保存し再訪時にオフライン報酬を計算）

## 12. このゲームの一番の魅力（まとめ）

> **どれだけ速く打ち切れるか。そこからどこまで磨き込めるか。**

- 主役は最後までタイピング。上達がそのまま「高品質・高売上」になって返ってくる
- 作りたい作品が大きいほど打つ量が増え、手が忙しくなる（タイピングを卒業させない）
- 自動化と広告は難易度へのカウンター。ゼロにはせず"軽減"に留める
- 合間の経営判断（ジャンル掛け合わせ・トレンド・育成）で変化と奥行き
- 「速く正確に打てる自分」が会社を大きくしていく達成感
