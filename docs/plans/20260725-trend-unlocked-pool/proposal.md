# トレンドを「解放済みプール」から抽選する（黒字の運ゲー是正）

- **id**: `20260725-trend-unlocked-pool`
- **優先度**: P0（効き最大・変更は極小）
- **ステータス**: 未完了
- **出典**: 責任者が現ゲーム（`:5174`）を新規プレイヤーとして実プレイ（新規→採用→企画→開発→発売）＋ `src/data/trend.ts` 読解
- **最上位の目的**: 継続＝広告収益（game-design §0/§10）

## 2. 課題（Problem）

**トレンドは全ジャンル・全テーマの母集団から抽選されるのに、プレイヤーが選べるのは解放済みの一部だけ。** 新規プレイヤーではトレンド合致が構造的にほぼ不可能になっている。

実機（新規プレイ）で確認した事実：

- 今月のトレンド＝**FPS × 忍者**。一方、企画画面で選べるのは **パズル／アドベンチャー／シミュレーション × 寿司／温泉／農業**（stage1 の初期解放 3×3）。**合致が原理的に起こり得ない**。
- 企画画面の 🔒 表示より、ジャンルは 27 種（未解放 24）、テーマは 28 種（未解放 25）。図鑑の分母 756 = 27×28 と一致。

コード上の原因（`src/data/trend.ts:19-29`）：

```ts
export const newTrend = (now, rng = Math.random): Trend => ({
  genreId: pick(GENRES.map((g) => g.id), rng),   // ← 全 27 種から
  themeId: pick(THEMES.map((t) => t.id), rng),   // ← 全 28 種から
  expiresAt: now + TREND_DURATION_MS,
});
```

初期解放 3×3 のときの合致確率：

| 合致 | 確率 | 効果 |
|---|---|---|
| 両方 | 3/27 × 3/28 = **1.19%** | メタ +10・売上 ×1.10（`trend.ts:65,79`） |
| 片方 | **20.7%** | メタ +5・売上 ×1.05 |

トレンド寿命は 6 分（`TREND_DURATION_MS`）なので、両合致を待つと期待 84 ロール ≒ **実時間 8.4 時間**。狙って取れる設計になっていない。

そして roadmap §v0.28 B-2 の数値シミュ結論は「**トレンド両合致（メタ+10）が無いと、完璧タイパー（100）＋最良相性＋軸上限でも mini は必ず赤字**」。つまり黒字の必要条件が **1.19% のクジ**に置かれている。v0.29 で解放が購入制一本化になったぶん、序盤の解放プールは以前より小さく、この歪みは悪化している。

## 3. プレイヤー体験（Job Story）

プレイヤーが「**企画会議でジャンル・テーマを選ぶとき**」、「今の流行に乗せて売上を伸ばしたい」ので、「**画面上部に出ている『今月のトレンド』を見て、それを選ぶ**」。

いま同じ行動を取ろうとすると「トレンドのジャンルはロックされていて選べない」で終わる。**表示されている情報が行動に接続していない**。

## 4. 提案（What）＋UI導線・置き場所

- `newTrend` / `ensureTrend` に**候補プール（解放済みジャンル・テーマ）を渡す**。抽選母集団を解放済みに限定する。`src/state/gameStore.ts` のトレンド更新経路と `src/state/boot.ts` から `unlockedGenres` / `unlockedThemes` を渡すだけで済む（純粋関数の引数追加）。
- **UI は新規追加なし**。既存の導線がそのまま実効化する：
  - ステータスバー下の「今月のトレンド：◯ × ◯ が人気！」
  - オフィスの 📢 お知らせ「◯×◯ が人気です」
  - 企画画面の 📈 トレンド枠（「合致：スコア +5／+10・売上 +5%／+10%」は既に表示済み）
- 副次効果：v0.29 で解放が購入制になったため、**ジャンル/テーマを買う＝トレンド当選率が上がる**という投資の意味が生まれる（現状は買っても当選率は 1/27 のまま）。

🔧 **要社長判断**：抽選母集団を「**100% 解放済みプール**」にするか、「**解放済み 80% / 全体 20%**（未解放が来たら"憧れ枠"＝買う動機）」にするか。責任者の推奨は **100% 解放済み**（まず行動と情報を接続する。憧れ枠は効果を測ってから）。

## 5. なぜ今／最上位の目的リンク

- **継続（§10-①）**：「トレンドを狙って当てる」という毎作の意思決定が初めて成立する。今は狙えないので企画選択が実質ランダム＝退屈。
- **誰も弾かない（§10-②）**：黒字の必要条件が 1.19% のクジという状態は「腕でも判断でも越えられない壁」。序盤の破産ウォールを構成する主因のひとつ。
- **メタ進行（§10-④）**：ジャンル/テーマ購入（v0.21/v0.29）に「トレンド当選率が上がる」という明確なリターンが付き、投資が回り出す。
- **変更が極小**：純粋関数の引数追加のみ。経済式・UI・素材に触らない。効き／コスト比が今回の3件で最良。

## 8. リスク／要社長判断

- 🔧 **抽選母集団の方針**（100% 解放済み ／ 80:20 ハイブリッド）。上記の推奨は 100%。
- **序盤インフレのリスク**：解放数が少ない序盤ほど合致しやすくなる（3×3 なら両合致 11.1%）。逆に終盤は母集団が広がって合致しにくくなる＝**序盤に厚く終盤に薄い**カーブになる。序盤リテンションを買う設計としては狙いどおりだが、`solvencySimulation` / `progressionSimulation` で mobile 到達本数がズレないか要確認。
- コアループ改変ではない（トレンド機構そのものは維持）。
