# スコアと売上の算出方法

作品をリリースしたときに「評価点（メタスコア）」と「売上」がどう決まるかを、順番どおりにまとめる。
実装は `src/core/release.ts`（全体の流れ）と `src/utils/metascore.ts`（品質・メタスコア・売上の式）。

計算は **品質 → メタスコア → 売上 → 入金** の順に進む。

---

## 1. 品質（0〜100）

### 1-1. 4つの要素スコアを合成する
それぞれ 0〜100 の4要素を、決まった比率で足す（`QUALITY_WEIGHTS`）。

| 要素 | 中身 | 比率 |
|---|---|---|
| 社員スコア | 参加社員の能力を規模基準で 0〜100 にしたもの | **0.60** |
| 相性スコア | 選んだジャンル × テーマの相性を 0〜100 にしたもの | 0.15 |
| タイピングスコア | タイピング成績から出す（下記 1-3） | 0.15 |
| 運 | **50 固定** | 0.10 |

```
品質の素 = 社員×0.6 + 相性×0.15 + タイピング×0.15 + 50×0.1
        → × 運の揺らぎ（0.97〜1.03） → 0〜100 に丸め
```
→ **社員が6割**を占める。ここが一番効く。

### 1-2. 開発中に積んだ分を上乗せして確定
```
品質 = 品質の素
     ＋ 積み上げボーナス（企画の 面白さ/使いやすさ/バランス ＋ devStats）… 合計 +8 で頭打ち
     − バグ率ペナルティ ・ 残バグを抱えて出したペナルティ
     → 0〜100 に丸め
```

### 1-3. タイピングスコアの中身
```
基礎 30
＋ WPM（120 を基準に約 −25〜+30）
＋ 最大コンボ（50 / 150 / 300 / 600 で +5 / +10 / +18 / +25）
− 正確さ（97% 未満から減点、最大 −25）
＋ 残バグ 0 で +5
```
※ 発売時の広告でタイピングスコアを +5 する旧仕様は**撤去済み**（広告はスコアに影響しない）。

---

## 2. メタスコア（評価点・0〜100）

**メタスコアはほぼ品質そのまま。** 品質に少しだけ足す。
```
メタスコア = 品質 ＋ トレンド補正 ＋ 評価家のブレ（±5）→ 0〜100 に丸め
   トレンド補正 = 両方合致 +10 / 片方合致 +5 / 合わない 0
```
→ トレンドはスコアに +10/+5 乗る（段をまたげば売上が跳ねる）。売上にも別途 +10%/+5%（下記）。

---

## 3. 売上（総額）

売上は **4つの掛け算**。
```
売上総額 = 規模の基準額 × 段の倍率 × ソフト補正 × 軸補正 × トレンド × マーケ広告
```

### 3-1. 規模の基準額
| 規模 | 基準額 |
|---|---|
| ミニゲーム | ¥30万 |
| スマホゲーム | ¥300万 |
| インディー大作 | ¥3000万 |
| 話題作 | ¥3億 |
| AAA | ¥30億 |

### 3-2. 段の倍率（← 売上のほとんどを決める）
メタスコアが入る「段」で倍率が階段状に決まる。
| メタスコア | 段 | 倍率 |
|---|---|---|
| 0〜29 | 致命的失敗 | ×0.33 |
| 30〜49 | 失敗 | ×3.33 |
| 50〜69 | 普通 | ×10 |
| 70〜79 | ヒット | ×33 |
| 80〜89 | 大ヒット | ×100 |
| 90〜94 | 名作 | ×250 |
| 95〜100 | 神ゲー | ×500 |

→ **段をまたぐ 1 点で売上が数倍**になる。ここがこのゲームの心臓部。

### 3-3. ソフト補正・トレンド・マーケ広告（各ボーナスは独立倍率＝表示どおり効く）
共有の +20% 上限は廃止（案B）。各ボーナスをそれぞれ独立の倍率として掛ける。
```
ソフト補正 = (1 + 社員PR) × (1 + ファン) × (1 + ローンチ広告) × (1 + 初回組合せ)
   社員PR   = 広報社員の「📣売上+○%」の合計（上限なし・+11%×2人 = 約+22% が効く）
   ファン   = √ファン数 / 400（最大 +15%）
   ローンチ広告 = +10%
   初回組合せ  = +5%
トレンド   = 両方合致 ×1.10 / 片方 ×1.05 / なし ×1.0
マーケ広告 = 見たら ×1.10
```
→ 各ボーナスは**表示どおり足し合う**（+20% で潰れない）。全部揃うと売上は伸びるが揃うのは稀。

### 3-4. 軸補正
```
軸補正 = 1 ＋ (売上予測 ＋ 話題性 − 炎上リスク)/100 → ×0.5〜×2 に制限
```

---

## 4. 入金のされ方
```
初動   = 売上総額 × 20%   … 発売直後に即入金
販売プール = 売上総額 × 80% … 数日かけて少しずつ（メタスコアが高いほど長く売れる）
```
（前払い開発費 devCost は企画開始時に既に徴収済み。イベントのコスト調整があれば初動から差し引く。）

---

## 要点（どのレバーが効くか）
- **品質**：社員(0.6) が最重要。相性・タイピング(各0.15)、運(0.1)、積み上げ(+8上限)。
- **メタスコア**：≒ 品質 ±5。トレンド合致で +10/+5（段をまたげば売上ジャンプ）。
- **売上**：**段の倍率（×0.33〜×500）が支配的**。各ボーナス（社員PR・ファン・広告・トレンド・初回）は独立倍率で表示どおり効く（共有上限は廃止）。
- 狙いは「メタスコアを次の段に押し上げること」。段の中で数点動いても売上は変わらない。
