主要決定は確定済み（§0）。1. **§1 骨格**（DevPhase + current.phase + 遷移）→ 2. **§2 レイアウト骨格 + §4 開発フェーズ配置**（既存タイピングを 3 カラムに載せる＝最短で「動く形」）→ 3. **§3 背景イメージ連動**（ui/phase→public/phase）→ 4. **§5 イベントエンジン＋新軸**（まず開発フェーズのイベント）→ 5. **§4 残りフェーズ中身**（企画/テスト/デバッグ/発売/完了）→ 6. **§5 リリース合流** → 7. **§6 検証**（ブラウザ実機）
